# pixel-jump

### Descrição:

Jogo de plataforma com foco no aprendizado de mecânicas de movimentação e uso de parallax layers.

---

### Tecnologias:

* **GDScript:** Linguagem usada.
* **Godot Engine:** Motor de jogo utilizado.
